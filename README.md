### 安装提示

- **macOS**：首次打开若提示「来自身份不明的开发者」，请前往 **系统设置 → 隐私与安全性**，点击「仍要打开」。
- **Windows**：若 SmartScreen 拦截，点击 **更多信息 → 仍要运行**。
