### 安裝提示

- **macOS**：首次開啟若提示「來自未知的開發者」，請前往 **系統設定 → 隱私權與安全性**，點選「強制打開」。
- **Windows**：若 SmartScreen 攔截，點選 **更多資訊 → 仍要執行**。
