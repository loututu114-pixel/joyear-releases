# joyear角崖

> 桌面端漫画 / 画廊阅读器 —— 支持 macOS 与 Windows

本仓库为 **joyear角崖** 的官方下载入口。源代码不在此仓库，这里仅发布可直接下载安装的正式版本。

---

## 下载

前往 **[Releases](../../releases/latest)** 页面获取最新版本。

| 平台 | 文件 | 说明 |
| --- | --- | --- |
| macOS（Apple Silicon / M 系列） | `EhViewer Desktop-<版本>-arm64.dmg` | 推荐 |
| macOS（Intel） | `EhViewer Desktop-<版本>-x64.dmg` | |
| macOS（免安装） | `*-arm64-mac.zip` / `*-x64-mac.zip` | 解压即用 |
| Windows（安装版） | `EhViewer Desktop-<版本>-x64-setup.exe` | 推荐 |
| Windows（便携版） | `EhViewer Desktop-<版本>-x64-portable.exe` | 免安装 |

### 安装提示

- **macOS**：首次打开若提示「来自身份不明的开发者」，请前往 **系统设置 → 隐私与安全性**，点击「仍要打开」。
- **Windows**：若 SmartScreen 拦截，点击 **更多信息 → 仍要运行**。
